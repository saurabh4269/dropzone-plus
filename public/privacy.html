Privacy

Last updated 26 October 2026

DropZone is an open source project. This page explains what the website, the app and the optional local server do with your data. The short version: your yard data stays on your device, and drone carriers only ever receive a hold signal with a reason code.

What stays in your browser

  • Drop zones, zone names and descriptions, hazards you mark, delivery history, partner choices and settings are stored in this browser's local storage.
  • Camera frames are analysed in your browser with TensorFlow.js. They are not uploaded.
  • You can remove everything at any time from Settings, then Delete all my data, in the app.

What the optional server does

  • If you run DropZone locally with a Ring token, the server calls the Ring Partner API on your behalf. Your token is never sent to the browser.
  • The server keeps only the latest zone verdict, in memory. It does not store frames or video.
  • If you turn on Amazon Rekognition, frames are sent to your own AWS account for labelling. This is off by default.

What a drone carrier receives

HOLD with reason codes such as PERSON_IN_ZONE, or NO_ADVISORY, plus timestamps. Never images, video, faces, plates or identities. In this project the carrier is simulated.

This website

The site is hosted on GitHub Pages. It sets no cookies and runs no analytics. Fonts are served from this site. The app loads the COCO SSD detection model from jsDelivr when detection runs. GitHub may keep standard server logs under its own privacy statement.
